# 🚀 DataForge: Headless ComfyUI Automation Engine

A production-ready Python automation engine that batch-generates AI images via the ComfyUI API. No UI clicking. No manual work. Just pure, scalable Python automation.

## 🧠 Why DataForge?
Manual AI image generation doesn't scale. DataForge solves this by:
- ✅ **CSV-Driven:** Feed it a spreadsheet of 10, 100, or 1000 prompts.
- ✅ **Headless Execution:** Runs entirely via HTTP/WebSocket API in the background.
- ✅ **Auto-Sorting:** Automatically names and saves outputs with batch tracking.
- ✅ **Proxy-Resilient:** Built-in localhost bypass for stable local network routing.
